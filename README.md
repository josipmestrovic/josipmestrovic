### Hi, I'm Josip 👋

My repositories are mostly focused on tiny reusable components that are getting continuously updated as I use / test them. 

These stuff are small but they solve a specific problem pretty well. 
 
When these stuff get enough testing and iteration, I upload them to WordPress repository for free as a open source. 

For example, I uploaded [Tab Teaser](https://github.com/josipmestrovic/tab-teaser) - a small plugin that can change the title and favicon of a tab when it is inactive (user clicked on another tab, but didn't close yours).
